## 问题一：中文顶刊中研究"分析师预测分歧 / 投资者意见分歧"与股票收益、定价、崩盘的论文

### Takeaway
中文期刊对 Miller（1977）"意见分歧 + 卖空限制 → 高估 → 未来低收益"的检验，主力在《管理科学学报》《金融研究》，而且几乎都用**换手率类指标**（去掉流动性、信息成分后的"未预期换手率"）或账户交易数据来度量投资者异质信念，以融资融券（2010 年起）作为放松卖空限制的冲击；用**分析师 EPS 预测标准差**直接预测未来收益的论文，本轮在《经济研究》《管理世界》《金融研究》里没有找到。分析师分歧在中文文献里多半是**被解释变量**（衡量信息环境）或**中介变量**，不是定价因子。

### Cited Findings

**A. 意见分歧（异质信念）→ 股票收益 / 高估（Miller 检验）**

- **朱宏泉、余江、陈林（2016）《异质信念、卖空限制与股票收益——基于中国证券市场的分析》，《管理科学学报》19(7): 115–126**（已核实：摘要页 + 他文参考文献）。度量：用"换手率分离模型"算出未预期交易量作为异质信念。结论：异质信念高的组合当期收益更高、下一期收益更低，小盘股最明显；控制流动性、动量后仍成立；2010 年后可卖空的股票，异质信念对下一期收益的影响不再显著，作者认为这验证了 Miller 理论，说明卖空机制能部分纠正定价偏差 — [jmsc 摘要页](https://jmsc.tju.edu.cn/jmsc/article/abstract/20160710)；书目见 [金永红等 2021 参考文献表](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
  - 该"换手率分离"做法的细节（金永红等 2021 照搬朱宏泉等 2016）：先用 FF3 拟合个股日收益得到市场成分和公司特有成分，再把日换手率 TO 对这些成分的正部分、负部分回归，拟合值 TcO 代表流动性需求和市场、公司信息引起的交易，残差 HB = TO − TcO 即"异质信念引起的交易"，季度值取三个月的平均 — [金永红等 2021 全文](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- **孟庆斌、黄清华（2018）《卖空机制是否降低了股价高估？——基于投资者异质信念的视角》，《管理科学学报》21(4): 43–66**（已核实：摘要页）。样本为融券标的股，从异质信念角度检验卖空对高估的影响：卖空者通过反映悲观情绪或负面信息压低高估程度，机制越成熟，抑制作用越强；卖空者既用公开信息也挖掘私有信息；卖空量越大，降低高估越明显，卖空者能识别被高估的股票 — [jmsc 摘要页](https://jmsc.tju.edu.cn/jmsc/article/abstract/20180403)
- **陈国进、胡超凡、王景《异质信念与股票收益——基于我国股票市场的实证研究》**（期刊和年份**未核实**：厦门大学页面只列为"已发表"的工作论文，他文引用写作"陈国进、胡超凡、王景（2009）"）。度量：调整后的换手率和收益波动率。样本 1997–2007 年，用组合分析和横截面回归。结论：卖空限制下异质信念使当期股价高于基本面，与未来收益负相关，经 Fama-French 四因子调整后仍成立；中国的高估比美国更严重、更持久 — [厦大页面](https://soe.xmu.edu.cn/english/info/7322/21231.htm)；[论文 PDF](https://econpub.xmu.edu.cn/research/repec/upload/2007919164157055475115776.pdf)
- **俞红海、李心丹、耿子扬（2015）《投资者情绪、意见分歧与中国股市 IPO 之谜》，《管理科学学报》18(3): 78–89**（已核实：摘要页）。用账户交易数据里投资者 IPO 首日净买入构造情绪指标（买卖失衡 BSI）。结论：首日情绪和意见分歧都显著正向解释首日回报，分歧越大，情绪的作用越强；首日情绪显著负向影响长期超额回报，意见分歧对长期回报**没有**影响。分歧的具体度量摘要页没有写 — [jmsc 摘要页](https://jmsc.tju.edu.cn/jmsc/article/abstract/20150307)
- **张维、张永杰（2006）《异质信念、卖空限制与风险资产价格》，《管理科学学报》9(4): 58–64**（书目已核实）。理论模型，是中文文献中"异质信念 + 卖空限制 → 高估"的常用理论依据 — [jmsc PDF](https://jmsc.tju.edu.cn/ch/reader/create_pdf.aspx?file_no=20060408&flag=1&journal_id=jmsc)；[金永红等 2021 参考文献表](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- 非顶刊、仅作背景：尹慧、赵国庆（2013）《异质信念、卖空限制与股票收益》，《上海经济研究》25(12)，结论是异质信念越大，预期收益越低 — [金永红等 2021 参考文献表](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- 综述（可当变量和文献索引用）：金永红、罗丹（2017）《异质信念、投资者情绪与资产定价研究综述》，《外国经济与管理》39(5): 100–114（书目已核实）；陈国进、王景《异质信念与金融异象研究最新进展》（期刊未核实）。后者认为分析师预测分歧是最基础的度量（盈利预测标准差），但有争议：它只反映职业分析师的信念且混有不确定性，换手率和收益波动率可能是更好的代理 — [金永红等 2021 参考文献表](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)；[陈国进、王景综述 PDF](https://core.ac.uk/download/41362983.pdf)
- 金永红等（2021）把三类异质信念代理的优缺点列成表：分析师预测差异"代表机构预测分歧、易于理解"，但因果难定；换手率"数据易得、有代表性"，但混有流动性；收益波动率数据易得，但缺少理论。作者认为换手率最适合 A 股 — [金永红等 2021 全文](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)

**B. 意见分歧 → 股价崩盘 / 暴跌**

- **陈国进、张贻军（2009）《异质信念、卖空限制与我国股市的暴跌现象研究》，《金融研究》2009 年第 4 期**（书目已核实；页码有 80–90 和 80–91 两种写法）。基于 Hong & Stein（2003），用固定效应条件 Logit 模型，发现异质信念越严重，市场和个股暴跌的概率越大，建议推出融资融券和股指期货等双向交易工具 — [厦大 WISE 页面](https://wise.xmu.edu.cn/info/3621/174521.htm)；[厦大经济学院页面](https://soe.xmu.edu.cn/info/6491/574174.htm)
- 金永红、吉鹏等（2021）《分析师预测偏差、投资者异质信念和股价崩盘风险》，《外国经济与管理》43(6): 90–104（已核实全文；非顶刊，CSSCI）。样本 2008–2019 年 A 股，季度频率。链条为"分析师预测偏差 → 换手率型异质信念 HB → NCSKEW/DUVOL"，HB 起部分中介作用。**注意**：文中的"预测偏差" Bias = 各分析师 (FEPS − AEPS)/|AEPS| 的季度均值，衡量的是**乐观偏差**，不是分歧度 — [全文 PDF](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- 王爱群、李静波、萧朝兴、陈柔君（2019）《股价崩盘风险与分析师关注："趋之若鹜"还是"退避三舍"》（上财期刊社平台，具体刊名未核实）。按投资者分歧度分组，分歧度高的组里分析师关注受崩盘风险的影响更强 — [上财期刊社页面](https://qks.sufe.edu.cn/mv_html/j00003/201905/784b1b1a-f586-44a4-812c-c1d73be651bf_WEB.htm)
- **许年行、江轩宇、伊志宏等（2012）《分析师利益冲突、乐观偏差与股价崩盘风险》，《经济研究》47(7): 127–140**（书目已核实）。是"分析师 → 崩盘风险"的奠基文献，NCSKEW/DUVOL 的中文标准构造多引自此文 — [金永红等 2021 参考文献表](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- 肖土盛、宋顺林、李路（2017）《信息披露质量与股价崩盘风险：分析师预测的中介作用》，《财经研究》43(2): 109–120（书目已核实）— [金永红等 2021 参考文献表](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- 甘露润、张淑慧（2013）《公司治理、分析师关注与股票市场信息含量》，《财经问题研究》2013(6)（书目已核实；非顶刊）。据金永红等（2021）转述，分析师关注越多，分析师之间的预测分歧越大，并导致投资者异质信念增加 — [金永红等 2021 全文](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)

### Inferences
- 用户若用"分析师文本逻辑分歧"做 Miller 式检验，中文顶刊里可直接对标的是朱宏泉等（2016）和孟庆斌、黄清华（2018）。这两篇的度量都是换手率型，所以"分析师层面的分歧能否预测收益"在中文顶刊里基本是空白，可作贡献点；但张轶凡的工作论文提示要正面回应"分析师分歧 ≠ 投资者分歧"这个质疑。建议同时报告文本分歧与 EPS 预测标准差、换手率型 HB 的相关性，并做"控制后仍显著"的检验。
- 理论预测有两个方向可供检验：(1) Miller/Hong-Stein：分歧高 → 当期高估 → 下季低收益，卖空越受限越强，并伴随更高的崩盘风险；(2) 信息/风险观：分歧高 = 不确定性高或私有信息多 → 风险溢价为正。陈国进系列和朱宏泉（2016）支持 (1)；俞红海等（2015）发现分歧不影响 IPO 长期回报。
- 2024 年沪深 300 成分股基本都是两融标的，"是否标的"在横截面上几乎没有差异。卖空约束的调节应改用连续变量：融券余额/流通市值、融资余额/流通市值、融资买入占比。另外，据印象 2023 年下半年以来监管收紧融券，2024 年 7 月暂停转融券。**这一时间点本轮未核实**，若属实，可当作 2024 年样本内的时间序列冲击（暂停前后分歧-收益关系是否变强）。
- 金永红等（2021）给出一个直接可用的"季度频率"崩盘回归框架（季度 NCSKEW/DUVOL、季度 HB、季度 + 行业虚拟变量），和用户的公司-季度结构一致。

### Gaps
- 没能进入知网，《经济研究》《管理世界》《经济学（季刊）》中可能存在的"分析师预测分歧 → 股票收益"的论文没有逐刊检索。印象中有包锋、徐建国（2015）《异质信念的变动与股票收益》，《经济学（季刊）》，**未核实**作者、卷期和度量。

- 陈国进、胡超凡、王景一文的发表期刊未核实。
- 以股吧发帖分歧、文本分歧度量投资者意见分歧的顶刊论文（例如印象中段江娇、刘红忠、曾剑平 2017《金融研究》，孙鲲鹏、肖星等关于社交媒体与意见分歧的研究）本轮**未核实**。
- 未找到中文顶刊中"分析师评级分歧"或"目标价分歧"与收益关系的研究。

## 问题二：分析师研究（含文本类）常用的被解释变量及其构造

### Takeaway
中文分析师研究的被解释变量大致分两类：一类是市场端（短窗口 CAR、长窗口异常收益、股价同步性、崩盘风险、FERC、特质波动、换手率/流动性），一类是分析师端或公司端（预测准确度、偏差、分歧，盈余管理，融资约束，投资效率，创新）。其中崩盘风险和同步性的中文构造几乎都沿用许年行等（2012）与朱红军等（2007）。长窗口收益用 CH-3（Liu、Stambaugh、Yuan 2019）做风险调整已逐渐进入中文文献。

### Cited Findings
- **崩盘风险（中文标准构造）**：周收益对市场周收益的超前两期、滞后两期做扩展市场模型回归，R_i,t = α + β1·R_m,t−2 + β2·R_m,t−1 + β3·R_m,t + β4·R_m,t+1 + β5·R_m,t+2 + ε，取 W = ln(1+ε)。NCSKEW 是 W 的负偏度；DUVOL = ln[(n_u−1)·Σ_down W² / ((n_d−1)·Σ_up W²)]，按周特有收益高于或低于均值分为上下两组。参考 Kim 等（2011）和许年行等（2012）— [金永红等 2021 全文](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- **分析师预测偏差（乐观度）**：Bias_i,j,t = (FEPS_i,j,t − AEPS_i,t)/|AEPS_i,t|，同一公司同一季度对分析师取平均，借鉴游家兴等（2013，《管理科学学报》16(6): 67–84）— [金永红等 2021 全文](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- **CH-3 因子**：Liu, Stambaugh & Yuan（2019）"Size and value in China"，JFE 134(1): 48–69，已被中文论文引用（如金永红等 2021 的参考文献）— [金永红等 2021 参考文献表](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- **股价同步性、股价信息含量**：朱红军等（2007，《金融研究》）用这两项衡量分析师对市场效率的作用；周铭山等（《管理科学学报》）以 R² 为被解释变量研究明星分析师 — [jmsc 20160604](https://jmsc.tju.edu.cn/jmsc/article/abstract/20160604)
- **预测准确度、分歧度、跟踪人数、同步性**并列作为结果变量（官峰等 2018，《财经研究》）— [检索结果](https://qks.sufe.edu.cn/J/ArticleQuery/A05ce49a91-d088-4b37-8197-e00170adb5d4/CN)
- **IPO 首日回报和长期超额回报**作为分歧研究的被解释变量（俞红海等 2015）— [jmsc 20150307](https://jmsc.tju.edu.cn/jmsc/article/abstract/20150307)
- **股价高估或错误定价**作为被解释变量（孟庆斌、黄清华 2018；李科等 2014）— [jmsc 20180403](https://jmsc.tju.edu.cn/jmsc/article/abstract/20180403)
- 文本类分析师研究的被解释变量：研报标题前瞻性信息 → 投资收益（赵二龙等，2024，《系统工程理论与实践》）；研报新旧信息的信息含量（任飞等，2020，同刊）— [西交大学者页](https://scholar.xjtu.edu.cn/en/publications/%E5%88%86%E6%9E%90%E5%B8%88%E5%89%8D%E7%9E%BB%E6%80%A7%E4%BF%A1%E6%81%AF%E5%AF%B9%E8%82%A1%E7%A5%A8%E6%8A%95%E8%B5%84%E6%94%B6%E7%9B%8A%E7%9A%84%E5%BD%B1%E5%93%8D%E5%9F%BA%E4%BA%8E%E6%96%87%E6%9C%AC%E5%88%86%E6%9E%90%E7%9A%84%E9%87%8F%E5%8C%96%E7%A0%94%E7%A9%B6/)；[SETP2020-0116](https://sysengi.cjoe.ac.cn/CN/10.12011/SETP2020-0116)

#### 被解释变量目录（标准做法；代表文献注明核实状态）

| 变量 | 典型构造（标准做法） | 中文代表文献（状态） |
|---|---|---|
| 短窗口 CAR | 研报发布日 [0,1]、[−1,1]、[0,2] 的累计异常收益；AR = R_i − R_m（市场调整，R_m 用沪深 300 或综合 A 股流通市值加权），或用 [−250,−30] 窗口估计市场模型 | 文本语调、评级研究普遍使用（本轮未逐篇核实） |
| 长窗口异常收益 | 组合法：按分歧分组，持有 1 个季度、3 个月、6 个月，算等权和市值加权收益，取 FF3、Carhart4、FF5、**CH-3/CH-4** 的 α；回归法：Fama-MacBeth 未来收益对特征回归；也有买入持有超额收益 BHAR | 陈国进等（FF4 调整，已核实）；朱宏泉等 2016（已核实） |
| 股价同步性 SYNCH | 年度内周（或日）收益对市场和行业收益回归，SYNCH = ln[R²/(1−R²)] | 朱红军等 2007（书目已核实）；周铭山等（摘要已核实）；伊志宏、杨圣之、陈钦源 2019《中国工业经济》（**未核实**） |
| 崩盘风险 NCSKEW / DUVOL | 见上；通常年度，至少需约 30 个周观测，季度版本每期只有约 13 周 | 许年行等 2012（书目已核实）；潘越、戴亦一、林超群 2011《金融研究》（**未核实**）；褚剑、方军雄 2016（书目已核实） |

### Inferences
- 对用户的"下季收益"设计，最贴近中文顶刊规范的是：(1) 季度分组的组合 α，同时报告 CH-3 和 FF3/FF5；(2) 季度 Fama-MacBeth，控制 Size、BM、动量、反转、IVOL、换手率、EPS 分歧和盈余意外。作为扩展，可以把被解释变量换成下季的 IVOL、异常换手率、季度 NCSKEW/DUVOL（季度只有约 13 个周观测，可改用日收益版本）、下季财报公告窗口 CAR（检验"分歧在公告时消解"）、后续分析师的预测准确度和修正方向。
- 文本型逻辑分歧与 EPS 数值分歧是两种对象。可以把"数值分歧控制后文本分歧仍有增量"作为核心稳健性检验，也可以把数值分歧当作被解释变量，检验文本分歧是否预测未来的数值分歧或预测误差。

### Gaps
- 没有找到中文顶刊系统使用 CH-4（加入换手率型情绪因子 PMO）的分析师文献实例；CH-3 在中文分析师研究中的使用频率没有统计。
- PIN 在中文顶刊分析师研究中的具体用例本轮未核实。
- 伊志宏、杨圣之、陈钦源（2019）一文的设计未能核实。

## 问题三：常用的控制变量、机制变量与调节变量

### Takeaway
中文顶刊分析师研究的控制变量相当固定：公司财务（Size、Lev、ROA、BM 或 TobinQ、Growth、上市年龄）、治理（SOE、第一大股东持股、两职合一、独董比例、董事会规模、四大审计）、市场（换手率、过去收益、波动率），加上年度和行业固定效应；崩盘研究另加滞后 NCSKEW、Dturn、Sigma、Ret 和信息不透明度 ABACC。常用的调节或机制变量包括：融资融券（卖空）、沪深港通、机构持股、信息披露质量、市场化指数、明星分析师和券商声誉、利益冲突（承销或自营关系）、投资者关注（百度指数、股吧）、媒体报道。

### Cited Findings
- 季度频率崩盘研究的一套控制变量（已核实）：公司规模 Size（总资产对数）、Lev（总负债/总资产）、BM（账面价值/总市值）、Roa（净利润/总资产）、Return（周收益平均值）、Vol（周收益标准差的平均值）、投资者情绪综合指数 CICSI，以及季度和行业虚拟变量；控制变量滞后一期 — [金永红等 2021 全文](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- 金永红等（2021）的回归中，Roa 和 BM 对换手率型异质信念的系数在 1% 水平上显著为负：经营好的公司投资者分歧更小 — [金永红等 2021 全文](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- 朱宏泉等（2016）在组合和回归中控制**流动性、动量**，并以**是否可卖空（2010 年后）**为调节变量 — [jmsc 20160710](https://jmsc.tju.edu.cn/jmsc/article/abstract/20160710)
- 孟庆斌、黄清华（2018）以**卖空量**（连续变量）和**卖空机制成熟度**为调节或机制，并区分卖空者处理的是公开信息还是私有信息 — [jmsc 20180403](https://jmsc.tju.edu.cn/jmsc/article/abstract/20180403)
- 俞红海等（2015）以**意见分歧程度**调节情绪对首日回报的影响 — [jmsc 20150307](https://jmsc.tju.edu.cn/jmsc/article/abstract/20150307)
- 王爱群等（2019）以**投资者分歧度**为分组调节变量 — [上财期刊社页面](https://qks.sufe.edu.cn/mv_html/j00003/201905/784b1b1a-f586-44a4-812c-c1d73be651bf_WEB.htm)
- 《放松卖空管制对分析师预测行为的影响》（《金融研究》，作者未核实，印象中是王攀娜、罗宏 2017）以**牛熊市**为调节变量，卖空对分析师乐观度的影响在牛市中更强 — [金融研究摘要页](http://www.jryj.org.cn/CN/abstract/abstract14.shtml)
- 北航学报研究以**机构持股比例**调节融资融券对错误定价的影响 — [北航学报社科版](https://bhxb.buaa.edu.cn/bhsk/article/doi/10.13766/j.bhsk.1008-2204.2016.0163)
- **明星分析师**作为解释或调节变量（周铭山等，《管理科学学报》）；**利益冲突**（许年行等 2012 的标题即"利益冲突"）；**内部人减持前的分析师行为**（孙淑伟、梁上坤、付宇翔等 2019，《管理科学学报》22(12): 105–123，书目已核实）— [jmsc 20160604](https://jmsc.tju.edu.cn/jmsc/article/abstract/20160604)；[金永红等 2021 参考文献表](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- 政治关联冲击（腐败官员落马）作为外生冲击，分析师作为中介（官峰等 2018）— [检索结果](https://qks.sufe.edu.cn/J/ArticleQuery/A05ce49a91-d088-4b37-8197-e00170adb5d4/CN)

| 利益冲突 | 承销关系、券商自营或基金重仓、佣金分仓 | 匹配 IPO、增发主承销商；基金分仓佣金 | CSMAR IPO/SEO、基金年报 |
| 投资者关注 | 百度指数（搜索量）、股吧发帖量和阅读量、东方财富或雪球帖子 | ln(1 + 发帖数)；异常搜索量 | CNRDS（GUBA、百度指数） |
| 投资者分歧（非分析师） | 股吧帖子看涨看跌分歧、换手率型 HB | Antweiler-Frank 分歧指数 | CNRDS 股吧情绪 |
| 媒体 | 新闻报道数、媒体语调 | ln(1 + 报道数) | CNRDS 新闻库（CFND）、Wind |
| 投资者情绪 | CICSI、BSI | 市场层面主成分 | CSMAR 情绪指标 |
| 牛熊市 | 市场状态虚拟变量 | 按指数阶段划分 | 价格数据 |

### Inferences
- 用户样本是 2024 年沪深 300，样本内大多数制度类调节变量（两融标的、沪深港通标的、四大审计）几乎不变，按"是否标的"分组没有区分力。能用的调节变量应是连续变量：融券余额占比、北向持股比例和变动、机构（基金）持股比例、分析师跟踪人数、明星分析师占比、股吧关注度、IVOL（套利限制）、规模。
- 机制链可以照"文本分歧 → 投资者分歧（HB 或股吧分歧）→ 高估 / 下季低收益或崩盘"来设计，与金永红等（2021）的中介框架同构，但要换成更可信的中介检验（例如分组和交互，而不是三步法）。
- 套利限制（IVOL、规模、低机构持股、低流动性）是检验 Miller 渠道最常用的调节项，可以直接用日价格和市值算出来（见问题四）。

### Gaps
- 深交所信息披露考评主要覆盖深市公司，沪市考评的起始年份和可得性本轮未核实；沪深 300 跨两所，需要分别处理。
- 新财富评选 2024 年的现状（是否仍按原口径进行）本轮未核实。
- 樊纲市场化指数的最新覆盖年份未核实（印象中最新版报告到 2019 年前后），用 2024 年样本时可能只能沿用旧年份。

## 问题四：哪些变量能用"日价格 + 总市值 + 季度财务"自行计算，哪些要外部数据库

### Takeaway
用户现有数据（后复权收盘价、总市值、季度资产/负债、TTM 营收/净利润）能直接算出大部分收益型和估值型变量：收益、动量、反转、β、IVOL（因子可从市值和净资产自建，或下载 CH-3）、MAX、偏度、NCSKEW/DUVOL、同步性，以及 Size、BM、EP、SP、Lev、ROA、增长率和季节性随机游走的 SUE 分子。凡涉及**成交量**（换手率、HB、Amihud、异常交易量）、**分析师数值预测**（EPS 分歧、准确度）、**治理和股权**、**两融和北向**、**关注和媒体**的变量，都需要 CSMAR、Wind 或 CNRDS。

### Cited Findings
- 换手率型异质信念 HB 需要日换手率（成交股数/流通股数）加 FF3 回归，属于"日交易数据 + 因子数据"的组合 — [金永红等 2021 全文（公式 5–8）](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- 崩盘指标只需要周收益和市场周收益（扩展市场模型的残差）— [金永红等 2021 全文](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)
- CH-3 因子来自 Liu, Stambaugh & Yuan（2019，JFE），中文论文直接引用 — [金永红等 2021 参考文献表](https://qks.sufe.edu.cn/j/PDFFull/4f09876d-125a-457e-a979-6d6ff58fc088.pdf)

#### 可得性对照表

| 变量 | 仅用现有数据能否计算 | 说明或所需外部数据 |
|---|---|---|
| 下季（月）收益、BHAR | 能 | 后复权收盘价算收益（后复权已含分红送转，近似总收益） |
| 市场调整收益、CAR | 能（需市场基准） | 可用样本内市值加权自建基准；更规范的做法是下载沪深 300 或 Wind 全 A 指数日收益 |
| 动量、反转、MAX、偏度、波动率、β | 能 | 日收益 |
| IVOL（FF3、CH-3 残差） | 基本能 | 因子可自建：SMB 用总市值，HML 用（资产 − 负债）/市值，CH-3 的 EP 用 TTM 净利润/市值。但沪深 300 截面太窄，**建议下载全 A 因子**（Stambaugh 网站 CH-3、CSMAR 或 RESSET 三因子）；无风险利率需另取 |
| 股价同步性 R² | 基本能 | 还需市场和行业收益：行业分类（申万、证监会）要外部取得 |
| NCSKEW / DUVOL | 能 | 周收益 + 市场周收益 |
| Size、BM、EP、SP、Lev、ROA、营收或利润增长 | 能 | 净资产 = 资产 − 负债（未区分少数股东权益，可接受）；EP = TTM 净利润/市值；SP = TTM 营收/市值 |
| SUE（季节性随机游走） | 部分能 | TTM_q − TTM_{q−1} = NI_q − NI_{q−4}，正好是季节性随机游走的意外盈余分子；分母可用市值或过去 8 季该差值的标准差。公告日要外部取得（CSMAR 财务报告披露日） |
| 公告窗口 CAR（财报、研报发布） | 部分能 | 需财报公告日（CSMAR、Wind）；研报发布日用户自有研报数据里已有 |
| 换手率、Dturn、HB、异常交易量 | **不能** | 需日成交量和流通股本（CSMAR 日个股交易文件、Wind） |
| Amihud、买卖价差、PIN | **不能** | 需成交额；PIN 需逐笔数据（CSMAR 高频） |
| EPS 预测分歧、准确度、乐观偏差、修正、跟踪人数 | 部分能 | 跟踪人数和研报数可由用户自有研报统计；数值预测需 CSMAR 分析师预测库、Wind 或朝阳永续一致预期 |
| 评级、目标价分歧 | 部分能 | 若 LLM 抽取能同时取出评级和目标价，可以自算；否则用 CSMAR 或 Wind |
| SOE、Top1、机构持股、两职合一、独董、四大 | **不能** | CSMAR 治理库、股权性质库，Wind |
| 融资融券余额、标的 | **不能** | CSMAR 融资融券库、Wind、交易所 |
| 北向持股 | **不能** | CSMAR 沪深港通库、Wind |
| 明星分析师、券商声誉 | **不能** | 新财富名单（手工整理）、CSMAR 分析师库的券商字段 |
| 百度指数、股吧、媒体 | **不能** | CNRDS（GUBA、CFND） |
| 信息披露考评、市场化指数 | **不能** | 交易所、CSMAR；樊纲指数报告 |
| 盈余管理（DA）、ABACC | 部分能 | 修正 Jones 需经营现金流、应收、PPE，现有季度字段不够，要用 CSMAR 财务报表全表 |
| 创新、ESG | **不能** | CNRDS 专利库、CSMAR 研发；华证、Wind ESG |

### Inferences
- 用户数据的最大短板是**没有成交量**。而 A 股文献里分歧和定价最主流的代理（换手率、HB）以及套利限制里的流动性都依赖成交量，所以优先补 CSMAR 日个股回报率文件（含成交股数、成交额、流通市值）收益最大。常见字段名如 Dnshrtrd、Dnvaltrd、Dsmvosd、Dretwd，凭印象列出，本轮未核实。
- 第二优先是 CSMAR 分析师预测库，或用 LLM 从同一批研报中抽取 EPS 预测、评级、目标价，这样能在同一样本上并排比较"数值分歧 vs 逻辑分歧"。
- 沪深 300、2024 年 4 个季度约 1,200 个公司-季度观测，分 5 组每组每季只有约 60 只股票，组合检验功效有限。可以用三分组加 Fama-MacBeth 回归互补，并把 2023 年或 2025 年的数据扩进来做样本外检验（此为推断）。
- 后复权收盘价算出的收益已含分红再投资效应（近似），可以直接用于 CAR 和组合收益；但总市值不能替代流通市值来算换手率或做加权，加权时用总市值是可以的。

### Gaps
- CSMAR 字段名、Stambaugh 网站 CH-3 因子的更新时点（是否覆盖 2024 年各月）本轮未核实。
- CNRDS 股吧和百度指数在 2024 年的覆盖情况未核实。
