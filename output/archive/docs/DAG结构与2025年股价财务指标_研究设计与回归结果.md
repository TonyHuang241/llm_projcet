# 概念 DAG 结构与公司次年股价、财务表现：研究设计与回归结果

2026-11-21。问题：2024 年研报里抽出的概念 DAG 的三个结构指标（源汇比、路径数、平均路径长度），和这些公司 2025 年的股价指标、财务指标有没有关系。样本是 2024 年沪深300 成分股中有研报 DAG 的 241 家公司、791 篇研报。

## 结论

- **财务指标**：DAG 结构基本不能预测 2025 年的财务表现。15 个年度财务指标 × 3 个 DAG 指标共 45 个系数，公司层面按置换检验只有 1 个在 5% 水平显著，研报层面没有一个在 10% 水平显著；6 个季度指标也没有一个在 5% 水平显著。
- **唯一例外**：源汇比高的公司，2025 年资产负债率下降更多（高 1 个标准差，低 0.41 个百分点；置换检验 p = 0.005，换申万行业后 p = 0.030）。但研报层面不显著，按检验个数校正后不能排除是碰巧。
- **股价指标**：按证监会门类控制行业时，路径数多、路径长的研报对应的公司，2025 年同步性、波动率、换手率更低。换成申万一级行业后这些关系都消失，说明它来自申万行业之间的差异，不是同行业内公司之间的差异。
- **年报期累积回报**：带方向的累积超额收益与 DAG 指标基本无关。源汇比高的公司，2024 年年报公告窗口的绝对超额收益更大，各口径方向一致，但 2025 年年报没有重复出现。
- **崩盘风险**：NCSKEW 不显著；DUVOL 与路径数、路径长度正相关，换申万行业后不显著。
- **整体**：没有发现 DAG 结构指标对次年股价或财务指标有可靠的预测关系。样本只有一年、约 240 家公司，这是“没有找到”，不是“证明没有”。

## 1 变量定义与构造

解释变量取自 2024 年的研报，被解释变量取 2025 年，控制变量取 2024 年。所有连续变量在 1%、99% 分位缩尾。股价同步性的算法、30 周的最低要求、缩尾取自伊志宏等（2019）；崩盘风险指标和上期值作控制取自马黎珺等（2022）。

### 1.1 解释变量：DAG 结构指标

每篇研报一张图。源点是没有入边的概念，汇点是没有出边的概念。

| 变量 | 研报层面的定义 | 公司层面 |
|---|---|---|
| 源汇比 `RATIO` | 源点数 ÷ 汇点数 | 该公司各篇的均值 |
| 路径数 `LNPATH` | ln(1 + 从任一源点到任一汇点的不同有向路径条数) | 各篇对数值的均值 |
| 平均路径长度 `PATHLEN` | 上述所有路径的边数的均值 | 各篇的均值 |

进回归前，三个指标在回归样本内标准化。系数的含义是：指标高 1 个标准差，被解释变量变化多少。

### 1.2 被解释变量：股价指标（2025 自然年）

周收益 = 本周最后一个未停牌交易日的后复权收盘价 ÷ 上一个有交易的周的最后收盘价 − 1。一年不足 30 个周收益的公司，周收益类指标记为缺失。市场组合是全部沪深 A 股按上周末总市值加权；行业组合同理，并剔除本股自己。

| 变量 | 定义与构造 |
|---|---|
| 股价同步性 `SYNCH` | 对每只股票每年估计 R_i,w = β0 + β1·RM_w + β2·RM_{w−1} + β3·RI_w + β4·RI_{w−1} + ε，RM 是市场周收益，RI 是同行业其他股票的市值加权周收益（行业用证监会门类）；SYNCH = ln(R² ÷ (1 − R²)) |
| `SYNCH_SW` | 同上，行业换成申万一级 |
| `SYNCH_MKT` | 回归里只放市场收益（当期和滞后一期） |
| 负收益偏态系数 `NCSKEW` | 扩展市场模型 R_i,w = α + Σ_{k=−2..2} β_k·RM_{w+k} + ε，W = ln(1 + ε)；NCSKEW = −[n(n−1)^{3/2}·ΣW³] ÷ [(n−1)(n−2)(ΣW²)^{3/2}]。数值越大，崩盘风险越高 |
| 收益上下波动比 `DUVOL` | 同一组 W，按是否低于年均值分成下跌周（n_d 个）和上涨周（n_u 个）：DUVOL = ln{[(n_u − 1)·Σ_下跌 W²] ÷ [(n_d − 1)·Σ_上涨 W²]}。数值越大，崩盘风险越高 |
| 特质波动率 `IVOL` | SYNCH 那个回归的残差标准差 |
| 总波动率 `SIGMA` | 周收益的标准差 |
| 年度回报 `RET` | 2025 年买入持有收益 |
| 年报期累积回报 `CAR_AR24[-1,1]`、`CAR_AR24[-1,5]` | 2024 年年报（2025 年披露）公告窗口的累积超额收益。第 0 天是公告日当天或之后第一个交易日；每日超额收益 = 个股日收益 − 市值加权市场日收益；窗口取 [−1,1] 和 [−1,5] 个交易日 |
| `ABSCAR_AR24` | CAR_AR24[-1,1] 的绝对值 |
| `CAR_AR25[-1,1]`、`CAR_AR25[-1,5]`、`ABSCAR_AR25` | 同上，换成 2025 年年报（2026 年披露） |
| 换手率 `TURN` | 日均换手率（%）= 成交量 ÷ 总股本 |
| 非流动性 `ILLIQ` | 日度 \|收益\| ÷ 成交额（亿元）的年均值，取对数 |

### 1.3 被解释变量：财务指标（2025 财年）

年度值取报告期 2025-12-31 的滚动四季值。“平均”指年初与年末的均值。

| 类别 | 变量 | 定义 |
|---|---|---|
| 盈利能力 | `ROA` | 净利润 ÷ 平均总资产 |
| | `ROE` | 归母净利润 ÷ 平均净资产 |
| | 销售净利率 `NPM` | 净利润 ÷ 营业总收入 |
| | 毛利率 `GM` | 1 − 营业成本 ÷ 营业收入（只算非金融） |
| | 总资产周转率 `ATO` | 营业总收入 ÷ 平均总资产 |
| 成长与业绩变化 | `DROA` | ROA(2025) − ROA(2024) |
| | `REVG` | 营业总收入同比增速 |
| | `NPG` | 归母净利润同比：(2025 − 2024) ÷ \|2024\| |
| | `OPG` | 营业利润同比：(2025 − 2024) ÷ \|2024\| |
| | `ASSETG` | 总资产增速 |
| 现金流与盈余质量 | `CFO` | 经营现金流净额 ÷ 平均总资产 |
| | 应计利润 `ACC` | (净利润 − 经营现金流净额) ÷ 平均总资产（只算非金融） |
| | `EARNVOL` | 2025 年四个季度单季 ROA 的标准差 |
| 资本结构与投入 | `DLEV` | 资产负债率的变化：2025 年末 − 2024 年末 |
| | `RD` | 研发费用 ÷ 营业收入（只算非金融） |

季度指标（2025 年第 1 至第 4 季度）：

| 变量 | 定义 |
|---|---|
| `ROA_Q` | 单季净利润 ÷ 季末总资产 |
| `REVG_Q` | 单季营业总收入同比 |
| `NPG_Q` | 单季归母净利润同比：(本季 − 上年同季) ÷ \|上年同季\| |
| `GM_Q` | 单季毛利率（只算非金融） |
| `CFO_Q` | 单季经营现金流净额 ÷ 季末总资产 |
| `SUE_Q` | (单季归母净利润 − 上年同季) ÷ 上年末总市值 |

### 1.4 控制变量（全部取 2024 年）

| 变量 | 定义 |
|---|---|
| 公司规模 `SIZE` | ln(年末总资产) |
| 资产负债率 `LEV` | 年末总负债 ÷ 总资产 |
| 账面市值比 `BM` | 年末净资产 ÷ 年末总市值 |
| 上年 ROA `ROA24` | 2024 年 ROA |
| 上年换手率 `TURN24` | 2024 年日均换手率 |
| 上年回报 `RET24` | 2024 年买入持有收益 |
| 上年总波动率 `SIGMA24` | 2024 年周收益标准差 |
| 分析师关注度 `LNCOV` | ln(1 + 2024 年该股的个股研报篇数) |
| 概念数 `LNNODES` | ln(DAG 概念数)。路径数随图的大小机械增长，必须控制 |
| 研报字数 `LNCHARS` | ln(研报正文字数) |
| DAG 研报篇数 `LNNDAG` | ln(1 + 该公司抽出 DAG 的研报篇数) |
| 上年同一指标 | 被解释变量自己的 2024 年值 |

- 概念数、研报字数：公司层面回归用该公司各篇的均值，研报层面回归用这一篇自己的值。
- 上年同一指标：公告窗口的 CAR 类不加；ROA、总波动率、换手率、年度回报的上年值已在上面，不重复加。

## 2 回归模型

### 2.1 公司层面（表中第 1–4 列）

Y_i,2025 = α + β·DAG_i,2024 + γ′·控制变量_i,2024 + δ·Y_i,2024 + 行业固定效应 + ε_i

每家公司一个观测，DAG_i 是该公司 2024 年各篇研报指标的均值。标准误按行业聚类。

### 2.2 研报层面（表中第 5–8 列）

Y_i,2025 = α + β·DAG_r + γ′·控制变量_i,2024 + δ·Y_i,2024 + 行业 + 券商 + 发布月份固定效应 + ε_r

每篇研报一个观测，DAG_r 是这一篇的指标，Y 是研报所写公司的 2025 年指标。样本里不足 5 篇的券商并成“其他”。标准误按公司聚类。

### 2.3 季度财务面板（季度指标的表）

Y_i,q = α + β·DAG_i,2024 + γ′·控制变量_i,2024 + δ·Y_i,上年同季 + 行业×季度固定效应 + ε_i,q

每个公司—季度一个观测（2025 年四个季度）。标准误按公司聚类。

### 2.4 表格怎么读

每个被解释变量一张表，每列是一个回归：

- 三个 DAG 指标先各自单独进入回归，再三个一起进入。路径数与平均路径长度的相关系数是 0.74，一起进入时两者系数不稳定，判断以单独进入的列为主。
- Panel A 的行业固定效应用证监会门类，Panel B 换成申万一级。证监会门类把六成样本公司归进制造业，申万一级分得更细。
- 系数下面括号里是聚类 t 值，星号按它的 p 值：* 10%、** 5%、*** 1%。
- 公司层面按证监会门类聚类时只有约 12 个聚类，聚类 t 值容易虚高，所以这几列另给“置换检验 p 值”：把不含 DAG 指标的模型的残差在行业内随机打乱 2000 次，看真实 t 值排在什么位置。公司层面的显著性以它为准。
