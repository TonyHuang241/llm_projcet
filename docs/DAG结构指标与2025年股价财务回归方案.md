# 概念 DAG 结构指标与 2025 年股价、财务指标的回归方案

> 本文是最初的方案稿。完整的研究设计和回归结果见同目录《DAG结构与2025年股价财务指标_研究设计与回归结果.md》。

2026-11-21 定稿。问题：2024 年研报里抽出的概念 DAG 的结构（源汇比、唯一有向路径数、平均路径长度），和这些公司 2025 年的股价指标、财务指标有没有关系。

## 1 样本

- 公司：`data/hs300_2024_dag_covered.csv` 的 241 只（2024 年出现在沪深300 且至少 1 篇研报抽出 DAG）。
- 研报：`output_dag/deep/data/`（深度报告 974 篇）和 `output_dag/data/`（7 家试跑公司 65 篇）按 `report_id` 去重合并（两边都有的用 deep 的），只留这 241 只的，应为 791 篇。
- 主样本包含金融业；稳健性里剔除金融业（证监会门类“金融业”）。
- 2025 年内退市的：海通证券 600837（20250303）、中国重工 601989（20250904），按各指标的最少观测要求自然剔除，不特殊处理。行业文件里没有这两只，手工补：海通证券＝金融业／非银金融，中国重工＝制造业／国防军工。

## 2 解释变量：DAG 结构指标

每篇研报一张图，用 `src/viz/plot_dag_structure.py` 的 `measure`，输入是 `edges.parquet` 里 `in_dag` 为真的原始边（主口径）。

| 变量 | 研报层面 | 公司层面（主口径：各篇取平均） |
|---|---|---|
| `RATIO` 源汇比 | 源点数 / 汇点数 | 各篇均值 |
| `LNPATH` 唯一有向路径数 | ln(1 + 源到汇的路径条数) | 各篇 ln 值的均值 |
| `PATHLEN` 平均路径长度 | 各条路径边数的均值 | 各篇均值 |

- 三个指标分别单独进回归，再三个一起进一次。回归前在回归样本内标准化（减均值、除以标准差），系数含义是“指标高 1 个标准差，Y 变多少”。
- 稳健性口径：①公司内统一名称后的边（`unified_edges.parquet`，没有统一结果的研报用原始边）；②各篇取中位数；③只留 DAG 研报不少于 2 篇、3 篇的公司。

## 3 被解释变量

### 3.1 股价指标（2025 自然年）

收益率用 `daily_stock_data.parquet` 的后复权收盘价；周收益＝本周最后一个未停牌交易日收盘 / 上一个有交易的周的最后收盘 − 1，整周停牌的周丢掉；一年不足 30 个周收益的公司该指标记缺失（同伊志宏等 2019）。市场、行业组合只用沪深 A 股（代码 0、3、6 开头），按上周末总市值加权（数据里只有总市值 `mkcap`，没有流通市值，这是和原文的差别）。

| 变量 | 定义 |
|---|---|
| `SYNCH` 股价同步性（主） | 伊志宏等（2019）式(1)(2)：R_i,w = β0 + β1·RM_w + β2·RM_{w−1} + β3·RI_w + β4·RI_{w−1} + ε，RI 是同行业**剔除本股后**其他股票的市值加权收益；SYNCH = ln(R² / (1 − R²))。行业用证监会门类 |
| `SYNCH_SW` | 同上，行业换成申万一级（稳健性） |
| `SYNCH_MKT` | 只放市场收益（当期和滞后一期）的模型算出的同步性（稳健性） |
| `NCSKEW` 崩盘风险 | 扩展市场模型 R_i,w = α + Σ_{k=−2..2} β_k·RM_{w+k} + ε，W = ln(1 + ε)；NCSKEW = −[n(n−1)^{3/2} ΣW³] / [(n−1)(n−2)(ΣW²)^{3/2}]（W 先去均值） |
| `DUVOL` 崩盘风险 | 同一组 W，按是否低于年均值分下跌周、上涨周：ln{[(n_u − 1)·Σ_down W²] / [(n_d − 1)·Σ_up W²]} |
| `IVOL` 特质波动 | SYNCH 那个回归残差的标准差 |
| `SIGMA` 总波动 | 周收益的标准差 |
| `RET` 年度累积回报 | 2025 年买入持有收益 |
| `BHAR` | RET − 同期市场组合买入持有收益 |
| `CAR_AR24[-1,1]`、`CAR_AR24[-1,5]` 年报期累积回报（主） | 2024 年年报（2025 年披露）公告窗口的市场调整累积超额收益。公告日取 `financial_data.parquet` 里 `report_date = 20241231` 那行的 `date`；事件日 0 是公告日当天或之后第一个交易日；超额收益＝个股日收益 − 市值加权市场日收益 |
| `ABSCAR_AR24` | CAR_AR24[-1,1] 的绝对值（年报的信息冲击大小） |
| `CAR_AR25[-1,1]`、`CAR_AR25[-1,5]`、`ABSCAR_AR25` | 同上，换成 2025 年年报（2026 年披露，`report_date = 20251231`） |
| `TURN` | 日均换手率（成交量 / 总股本；总股本＝mkcap / 未复权收盘价，未复权价＝close / adj_factor） |
| `ILLIQ` | Amihud 非流动性：日度 \|收益\| / 成交额（亿元）的年均值，取 ln |

### 3.2 财务指标（2025 财年）

来自 `financial_data.parquet`（`report_date` 报告期、`date` 公告日；`_ttm` 是滚动四季、`_q` 是单季）。年度值用 `report_date = 20251231` 的 `_ttm`。

| 变量 | 定义 |
|---|---|
| `ROA` | 净利润 TTM / 年初年末总资产均值 |
| `ROE` | 归母净利润 TTM / 年初年末净资产均值（净资产＝总资产 − 总负债） |
| `DROA` | ROA(2025) − ROA(2024) |
| `REVG` | 营业总收入 TTM 同比增速 |
| `NPG` | 归母净利润同比：(2025 − 2024) / \|2024\| |
| `GM` | 毛利率：1 − 营业成本 / 营业收入（只算非金融） |
| `CFO` | 经营现金流净额 TTM / 总资产均值 |
| `ASSETG` | 总资产增速 |
| `DLEV` | 资产负债率的变化 |
| `RD` | 研发费用 / 营业收入（只算非金融；缺失不补 0） |
| `EARNVOL` | 2025 年四个季度单季 ROA（单季净利润 / 季末总资产）的标准差 |

季度面板（2025Q1–Q4，公司 × 季度）：`ROA_Q`、`REVG_Q`（单季收入同比）、`NPG_Q`（单季归母净利润同比）、`GM_Q`、`CFO_Q`、`SUE_Q`（(单季归母净利润 − 上年同季) / 上年末总市值）。

## 4 控制变量（全部取 2024 年，先于 Y）

| 变量 | 定义 |
|---|---|
| `SIZE` | ln(2024 年末总资产) |
| `LEV` | 2024 年末总负债 / 总资产 |
| `BM` | 2024 年末净资产 / 年末总市值 |
| `ROA24` | 2024 年 ROA |
| `TURN24` | 2024 年日均换手率 |
| `RET24` | 2024 年买入持有收益 |
| `SIGMA24` | 2024 年周收益标准差 |
| `LNCOV` | ln(1 + 2024 年这只股票的个股研报篇数)，来自 `data/hs300_2024_reports.parquet`（`is_stock_report` 为真），当作分析师关注度 |
| `LNNODES` | ln(各篇 DAG 进图概念数的均值)：路径数随图的大小机械增长，必须控制 |
| `LNCHARS` | ln(各篇研报正文字数的均值) |
| `LNNDAG` | ln(1 + 这家公司抽出 DAG 的研报篇数) |
| `Y24` | 被解释变量自己的 2024 年值（能算的都加：SYNCH、NCSKEW、DUVOL、IVOL、TURN、ILLIQ、各财务指标的上年值等；CAR 类不加） |

数据里没有机构持股、产权性质、交叉上市，这几个文献常用的控制变量加不了，结果里要写明。

所有连续变量在 1%、99% 分位缩尾。

## 5 回归模型

### M1 公司层面截面回归（主）

Y_i(2025) = β·X_i + γ′·Controls_i(2024) + 行业固定效应 + ε_i

- 行业固定效应：证监会门类（主）；申万一级（稳健性）。
- 标准误：按行业聚类（主，证监会门类约 15 类，聚类数少，p 值用 t(G−1) 分布）；同时报告异方差稳健（HC1）的 t 值；稳健性里用申万一级固定效应＋申万一级聚类（约 29 类）。

### M2 研报层面回归

Y_i(2025) = β·X_r + δ′·[ln 研报字数, ln 进图概念数] + γ′·Controls_i + 行业 + 券商 + 发布月份固定效应 + ε_r

- 每篇研报一个观测，Y 是公司的 2025 年指标；X 是这一篇的三个指标。
- 券商固定效应：样本里不足 5 篇的券商并成“其他”。
- 标准误：按公司聚类（约 241 类）。

### M3 季度财务面板

Y_{i,q}(2025Q1–Q4) = β·X_i + γ′·Controls_i + 行业 × 季度固定效应 + ε_{i,q}

- X 不随时间变，所以不加公司固定效应；标准误按公司聚类。

### 实现要求

- 项目环境没有 statsmodels、scipy、linearmodels，也不新装包：用 numpy 手写 OLS，固定效应用虚拟变量；聚类稳健方差用 CR1（同 Stata `reg ..., vce(cluster)`：三明治估计乘 G/(G−1)·(N−1)/(N−K)），p 值用 t(G−1)，t 分布的累积分布函数用 `mpmath.betainc` 算。
- 固定效应里只有一个观测的组（singleton）先剔除再估计，并记下剔除数。
- 写一个自检：用模拟数据核对（虚拟变量法和组内去均值法的系数一致；聚类数等于观测数时 CR1 和 HC1 一致）。

## 6 稳健性清单

1. 行业口径：申万一级固定效应和聚类。
2. 剔除金融业。
3. DAG 口径：统一名称后的边；公司层面取中位数；只留不少于 2 篇、3 篇的公司。
4. 同步性口径：`SYNCH_SW`、`SYNCH_MKT`。
5. 不加 `Y24`；不加 `LNNODES`（看路径数的结果有多少来自图的大小）。

## 7 输出

目录 `output_dag/regression/`：

- `firm_panel.parquet`：公司层面全部变量；`report_panel.parquet`：研报层面；`quarter_panel.parquet`：季度面板。
- `descriptives.csv`：各变量的观测数、均值、标准差、分位数。
- `correlations.csv`：三个 DAG 指标和各 Y 的 Pearson、Spearman 相关系数（缩尾后）。
- `reg_results.csv`：长表，一行一个系数（模型、样本/口径、Y、X、系数、标准误、t、p、观测数、R²、聚类数、固定效应、聚类维度）。
- `回归结果.md`：主要结果的表格（M1 主回归、M2、M3，以及稳健性摘要）。

## 8 解读时要注意

- 样本只有约 240 家公司，Y 有二十多个，X 有三个：按 5% 水平会有若干个系数碰巧显著，结论要看方向和显著性在不同口径下是否一致，不能只挑显著的。
- 这是相关性，不是因果：DAG 结构可能只是反映公司本身的复杂程度、所在行业或研报篇幅。
- 同文重抽时概念命名不稳定（见备忘 concept-dag-stability），结构指标有测量误差，系数会被压向 0。
