# MD&A 语调分解变量与年报公告后 CAR：8 个命题的检验

## 1. 结论

**8 个命题拆成 11 个事前指定的主检验，只有 P6（负面事实的位置）通过多重检验校正，但它不足以作为稳健结论。其余 10 个都不显著。** 总体上，没有证据表明这批由逐句原文和中性化得分构造的变量能稳健预测公告后 CAR。

- **主检验**：P6 的双向聚类 t = −2.97，BH q = 0.033，Bonferroni p = 0.033，方向符合预期。负面事实句的平均位置每靠后 1 个标准差，CAR[0,20] 低约 0.33 个百分点。其余 10 个检验的 p 值都大于 0.16，Bonferroni p 都是 1。
- **P6 只能算探索性证据**，原因有三：
  1. 公告前已有同向相关。CAR[−60,−21] 的系数 −0.037（t −3.70），绝对值比主窗口的 −0.024 更大，而此时年报还没发布。这与事前设想的“读者注意力递减、公告后逐步修正”不符，这个变量更可能代理了公司当年持续的坏消息。
  2. 结果依赖 2021 年口径断点和少数年份。吸收“公司 × 2021 前后”固定效应后，系数为 −0.018（t −1.92）；同时剔除 2012、2023 两年后，系数为 −0.012（t −1.33）。
  3. 通过校正的余量很小，上述替代规格下都无法通过 11 个检验的校正。
- **`sent_std_orig` 与 CAR 的正相关（P4）**：分解后的点估计显示，这一关系主要来自中性化后仍然存在的“事实离散度”（t 3.72），修辞起伏部分接近 0（t 0.37）。但两者之差不显著（t 1.40），而且窗口是已知结果，只能作为描述。
- **代码**：独立审查从逐句文件重建变量并重跑回归，11 个主检验全部精确复现，没有发现改变主检验数字的代码错误。

## 2. 研究设计

| 项目 | 做法 |
|---|---|
| 样本 | 2011–2023 年报，29,053 个事件；各主检验 N 为 18,683–23,880 |
| 事件日 | 公告日当天或之后的第一个交易日 |
| 因变量 | CAR[0,k]，市场模型，估计窗口 [−250,−21]；P5c 用 \|CAR\| |
| 回归 | CAR = 焦点变量 + 命题专属控制 + ln(总资产) + ROE + 杠杆率 + SUE + 公司 FE + 年份 FE |
| 缩尾 | 连续变量全样本 1%/99%；哑变量、等级差和乘积项不缩尾 |
| 标准误 | 公司 + 事件日双向聚类，判断显著性以此为准 |
| 文本长度 | 逐句分布型变量（P4–P8）要求不少于 20 句 |
| 2021 断点 | P1 主规格剔除 2021 年；其余用年份 FE，并分 2011–2020、2021–2023 两段报告 |
| 多重检验 | 在 11 个主检验内做 BH 和 Bonferroni；66 个“焦点变量 × 窗口”的结果仅作参考 |
| 校准 | 先复现基准结果：`car_15` 对 `sent_change_mean` 系数 0.011494（t 0.73），对 `sent_std_orig` 系数 0.047406（t 3.53），均已复现 |

**流程**：一个 Opus subagent 在不接触回归结果的情况下写定变量、预期符号和主窗口，一个 Sonnet subagent 实现并运行，另一个 Opus subagent 独立复算和审查。

单句得分 = P(正面) − P(负面)，`sc` 指 `sent_change_mean`（中性化后 − 原文的逐句均值）。

## 3. 命题与变量

设计阶段根据数据修改了多数原始思路，主要修改如下。

| 命题 | 焦点变量 | 含义 | 相对原始思路的修改 |
|---|---|---|---|
| P1 语调同比分解 | `d_neutral`、`d_rhet` | 事实语调同比变化；修辞同比变化 | 原式 `d_rhet = Δsc` 有误，两项之和不等于原文语调同比，改为 `d_rhet = −Δsc` |
| P2 修辞驱动的偏离 | `gap_delta` | \|Delta_原文\| − \|Delta_中性化\|，控制 \|Delta_中性化\| | 数据无证监会行业，退化为“年度 × 金融/非金融”分组 |
| P3 异常事实语调 | `at_neutral` | 中性化语调对基本面逐年回归的残差，控制原文异常语调 | 逐年估计，避免跨年前视 |
| P4 离散度保留比 | `ln_ret` | ln(中性化标准差 / 原文标准差) | 用对数比，避免比值回归的伪相关 |
| P5a 坏消息包夹 | `neg_sandwich_exc` | 负面句被正面句包夹，相对随机的超额程度 | 偏度基本是标签占比的函数（R² 0.87），改用此度量 |
| P5b 硬负面占比 | `hard_neg_share` | 带数字的中性化负面句占比 | 最低 10% 句均值已饱和（57% 的文档 ≤ −0.95），改用此度量 |
| P5c 套话占比 | `boiler_share` | 无数字的 neutral 句占比，因变量 \|CAR\| | neutral 句过半带数字，属于硬事实，故只取无数字部分 |
| P6 负面事实位置 | `pos_neg_fact` | 回顾性负面事实句的平均相对位置（0 开头，1 结尾） | 剔除风险句和前瞻句，否则结尾风险章节主导结果 |
| P7 单边修辞 | `one_sided` | −(正面句变化 + 负面句变化) | 两个变量符号相反，“差”改为和的相反数，并用 `two_sided` 分离总幅度 |
| P8 展望句修辞 | `sc_fwd` | 展望句的 `sc`，控制回顾句 `sc` 和展望句语调 | 去掉裸“将”等歧义规则，抽检精度约 90–95% |

## 5. P6 的压力测试

下列多数检验是审查时增加的，属于事后诊断，不能取代事前的主规格。

**支持结果的部分**

- 窗口没有被挑选：k = 8–20 全部显著，t 在 −2.97 到 −3.82 之间，k = 20 属于较弱的一档。
- 不由极小分母或离群值造成：剔除焦点变量上下 1% 后 t −2.90，上下 5% 后 t −2.54。
- 年内打乱焦点变量 500 次的排列检验 p = 0.004。
- 年-月 FE 下 t −2.98，事件日 FE 下 t −2.86；逐项加入文本长度、风险句占比、前瞻句占比等控制后，t 大多在 −2.4 到 −3.0。
- 把焦点换成正面句、中性句、回顾句的位置，都不显著（|t| ≤ 1.44），但全部负面句版本同样显著（t −2.73），所以“回顾性负面事实”这一区分并不干净。

**不支持结果的部分**

| 检验 | 系数 | t | 含义 |
|---|---:|---:|---|
| CAR[−60,−21]（公告前） | −0.0366 | −3.70 | 年报公布前已有同向相关 |
| 同上，估计窗改为 [−250,−61] | −0.0454 | −3.71 | 排除估计窗重叠后更强 |
| 2011–2020 | −0.0193 | −1.94 | 边际显著 |
| 2021–2023 | −0.0094 | −0.36 | 不显著，95% 区间约 [−0.061, +0.042]，功效低 |
| 公司 × 2021 前后 FE | −0.0180 | −1.92 | 焦点方差的 23.5% 来自公司内跨口径的变化 |
| 同时剔除 2012 和 2023 | −0.0121 | −1.33 | 这两年贡献约 51% 的协方差，方差占比仅 17% |
| 叠加全部结构控制 | −0.0174 | −1.57 | 单项控制稳定，叠加后不显著 |
| 去掉最后 10% 位置的句子 | −0.0129 | −1.56 | 系数约一半来自文末，且改变了样本 |
| 门槛提高到至少 10 句负面事实 | −0.0189 | −1.63 | 方向一致但不显著 |

**收益路径也不像逐步修正**：[0,4] 几乎没有反应（t −1.06），公告后收益集中在 [5,9]（−0.0170，t −4.13），[10,19] 都不显著。加入公告前 CAR 控制后，公告后系数基本不变（t −2.7 到 −3.1），所以它不是简单的动量延续。

**风险句规则偏窄**：文末 10% 的“负面事实句”中，有 39.5% 含“可能、或将、不确定”这类表述，前 90% 的位置只有 7.1%。排除这些句子后结果为 −0.0229（t −2.74），结论不变。

## 6. 其他值得注意的结果

**P4：离散度的来源。** 等价写法下，`ln_std_neutral` 系数 0.034（t 3.72），`ln_std_orig − ln_std_neutral` 系数 0.008（t 0.37）。点估计支持“`sent_std_orig` 的作用来自事实层面的离散度”，这与基准回归中 `sent_std_orig` 和 `sent_std_neutral` 的结果几乎相同（car_15 的 t 为 3.53 和 3.51）一致。不过焦点变量 `ln_ret`（两系数之差）不显著，所以不能断言修辞部分没有作用。这里的 car_15 窗口在设计前已知，不算独立的新证据。

**P5b：长窗口方向相反。** 主窗口不显著，但 k = 10、15、20 的系数为 +0.057、+0.085、+0.088（t +2.76、+3.35、+2.94），在 66 个结果的 BH 下 k = 15 和 20 的 q < 0.05。带数字的负面句越多，长窗口收益越高，与事前预期相反。效应主要来自 2015–2020 年（+0.148，t +3.29）。P5b 和已检验的 H8 相关 0.82，H8 的反向现象在设计时已知，因此不是独立证据，也不宜事后解释为支持某种假说。

**P2 的零结果不能解读为市场不惩罚修辞偏离。** 分组很粗（非金融公司不分行业），`gap_delta` 有 41% 为 0，噪声很大，只能说“在现有分组下未检出”。这也不是对王勇等（2023）的复现。

**P1、P3、P7、P8** 在主窗口和稳健性规格下都没有显著结果。P1 的两个系数之差也不显著（t −0.35）。

## 7. 局限

1. **事前性无法用版本记录证明**。`mda_tone/output/` 被 `.gitignore` 忽略，设计文档不在 git 中，只有文件时间先后自洽。今后建议先提交设计文档再运行。
2. **P2 的行业分类是当前最弱的一环**。如果有证监会门类数据，应重做 P2，并按新的事前规格对待。
3. **P4 和 P5b 的事前性打折**：P4 的窗口来自已知结果；设计时已看到 H8 的结论。
4. **规则类变量的精度**：前瞻句和风险句规则只由设计者单人抽检。规则漏掉无显式标记的祈使句，约 1/3 的匹配句是行业预测。
5. **未修正的小问题**：`verdict` 代码没有实现 P6 “两段同向才算支持”的条件（两段恰好同向，判定不变）；`P5a-sec` 替换焦点而不是并列，未记入 `deviations.md`。
6. **未独立重建的部分**：P3 一阶段的部分基本面变量（`btm`、`ret_y`、`std_ret`、`std_roe`）只核对了回归和残差；P2、P3 的部分稳健性项只做了代码审阅。这些都对应不显著的结果。
7. **未审查**：LLM 中性化质量和 FinBERT 分类本身不在本次审查范围内。
