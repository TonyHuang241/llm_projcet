# 每句情感变化均值（`sent_change_mean`）的扩展假说与 CAR 回归

## 1. 结论

**围绕每句情感变化均值构造的 24 个变量，只有 1 个通过多重检验校正，而且这个结果并不稳固。** 总体上，没有证据表明这类变量能稳健预测年报公告后的 CAR。

- **主检验**：24 条假说各有一个事前指定的窗口，只有 H9（粉饰 × 盈余好消息）显著，双向聚类 t = −3.16，BH q = 0.037，Bonferroni 校正后 p = 0.037。其余 23 条的 p 值都大于 0.13。
- **H9 的含义**：在 SUE ≤ 0 的年报里，每句情感下调越多（`sent_change_mean` 越负），CAR[0,3] 越低，斜率 +0.035（t = 3.01），1 个标准差的下调对应约 0.20 个百分点。在 SUE > 0 的年报里，这一关系不显著（斜率 −0.011，t = −1.03）。这和“坏消息配合粉饰更像掩饰”的事前假说一致。
- **H9 不稳固的地方**：
  1. 控制“原文语气 × 好消息”后，交互项降到 −0.024（t = −1.33），不再显著。`sent_change_mean` 和原文平均情感的相关系数是 −0.60，目前无法把它和原文语气的作用分开。
  2. 2021–2023 年的点估计接近 0（0.002，t = 0.04），但置信区间是 [−0.087, 0.091]，也包含全样本的估计值，所以既不能说效应消失，也不能说依然存在。
- **其他信号都只能算探索性线索**：见第 6 节，其中 H8 在 CAR[0,15] 的结果方向与事前预期相反。

## 2. 研究设计

| 项目 | 做法 |
|---|---|
| 样本 | 有年报情感评分的公司 × 年份，2011–2023 年报（29,053 个事件）；主检验 N 为 16,985–23,899 |
| 事件日 | 公告日当天或之后的第一个交易日 |
| 因变量 | CAR[0,k]，k = 3、5、7、10、15、20，市场模型，估计窗口 [−250,−21]，至少 120 个有效交易日；窗口内有停牌则该窗口缺失 |
| 市场回报 | 全市场按前一日总市值加权（数据中没有指数） |
| 回归 | CAR = b·焦点变量 + 主效应（如有）+ ln(总资产) + ROE + 杠杆率 + SUE + 公司 FE + 年份 FE |
| 缩尾 | 连续变量全样本 1%/99%，哑变量不缩尾 |
| 标准误 | 同时报告公司聚类和公司 + 事件日双向聚类；显著性判断以双向聚类为准（年报公告日高度集中） |
| 主检验 | 每条假说一个事前指定的窗口，共 24 个 |
| 多重检验 | 在 24 个主检验内做 BH FDR 和 Bonferroni；144 个检验的 BH 仅作参考 |

**基础变量**：单句情感 = P(正面) − P(负面)，`sent_change_mean` 是一份年报内“中性化后 − 原文”的逐句均值。它通常为负，越负表示语气被 LLM 下调得越多，本报告称之为“粉饰”，这是一种解读，不是已被验证的事实。恒等式 `sent_change_mean ≡ sent_mean_neutral − sent_mean_orig` 决定了这三者不能同时放进回归。

**防止数据挖掘的流程**：提出假说、构造变量的 subagent 没有接触 CAR 和回归结果，预期符号和主窗口在回归前已经写定；回归由另一个 subagent 按固定规格运行，不做调整。基准回归的两个已知结果（`car_15` 对 `sent_change_mean` 系数 0.011494，对 `sent_std_orig` 系数 0.047406）被精确复现。

## 3. 假说与变量

家族：A 句子分布统计（8 条）、B 粉饰与调节变量交互（9 条）、C 相对公司历史或同年的偏离（3 条）、D 文本内部一致性（4 条）。

交互项中 `sc_dm` 是缩尾后去均值的 `sent_change_mean`。因为 sc 越负粉饰越多，交互项系数为正表示调节变量越大时粉饰的负面作用越强，为负表示越弱。

## 8. 局限

1. **样本未含 2024 年报**：该年 FinBERT 分析尚未并入 `neutral_compare_glm_all`。
2. **分析师数据只到 2023-08**：2023 年报的 H11、H14 全部缺失，H11 中 `miss_consensus` 为 0 的组是少数（约 30%）。
3. **2021 年口径断点**：中位句数从约 150 跳到约 230。H2、H7、H18、H19 受影响较大。
4. **SUE**：用季节性随机游走（Q4 归母净利润同比差值 ÷ 此前 8 个季度差值的标准差），不是分析师口径。H9 的 `sue_pos` 把它二值化，切分点选在 0 也是事前决定的。
5. **ROE**：分子分母都含少数股东权益，数据里没有归母净资产。
6. **金融企业**：H12、H13 中已设为缺失（620 份年报），其他回归未剔除。
7. **换手率**：分母用总市值，数据没有流通市值。
8. **短文档**：有 600030/2012 这样疑似改写失败的文档（未改写率 1、sc 为 0），以及只有 1 句的文档；R4 剔除后结论不变。
9. **多重检验只覆盖 24 个主检验**：第 5 节的拆分、分时期和语气代理检验都是事后的，没有计入校正。
10. **公告日可能含更正日期**：少量晚于法定截止日的事件未剔除。
11. **未控制其他信息源**：比如业绩预告、同日其他公告；未加行业固定效应（数据里没有行业字段）。
